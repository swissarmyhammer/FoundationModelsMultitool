## Problem

Router ac2d7ba0 passes over a recording root that does not list, so the lists give the other sessions. Testudo must also tell the user which folder it cannot read.

## Fix

- `Query.unreadableFolders: [String!]!`: the path of each recording root that the directory cannot list (`SessionDirectory.unreadableRecordingRoots()`, Extras 3b1f82d). Only the host (no viewer) gets the paths; a session viewer gets none.
- The golden schema has the new field.

## Tests

`SessionsGraphUsageTests`: the field names the root of the directory, and the pinned list still gives the session; a directory with no such root gives none.
## Result

Done as planned. The full suite passed (3363 tests).

title: A gated probe that nests an unguided generation inside a tool call, to name the layer the deadlock lives in

A gated scenario hangs for ever (0% CPU, ~19GB resident) when both profile slots name one `ModelRef`, because `searchTools` generates from inside the outer turn's tool call.

Two explanations competed:

- **MLX**: the nested GRAMMAR-CONSTRAINED decode deadlocks (xgrammar shared per-model caches).
- **Router**: `RoutedModel.generationGate` — an `AsyncSemaphore(value: 1)` minted per resident container — is taken by `beginTurn()` and held for the WHOLE turn, tool calls included. A nested `respond` on the same container parks on `generationGate.wait()` and can never be admitted: the permit is freed by `endTurn()`, which needs the tool call to return, which needs the nested respond.

Router's explanation needs NO grammar. The MLX one needs one. That was the discriminator.

**Answer: it hangs with no grammar. Router's gate is the deadlock.** Measured twice on 2026-08-16 — `permits=0 waiters=1` throughout, 165 and 166 seconds parked inside one nested `respond`, unwound only by the outer turn's cancellation. See the run comment.

## What
- `MultiTool.swift` `RunCodeArguments` (today: only `code`) gains the explicit control surface, each with `@Guide` documentation and token constraints:
  - `waitSeconds` — first clock: how long this run blocks before it elevates; default the configured 5; `0` detaches immediately.
  - `timeout` — second clock: hard limit on the work; progress resets it.
- `MultiTool` conforms to the engine's `ElevationParameterProviding` protocol (defined in the ElevatingTool engine task) so the engine extracts these per-call clocks from the `runCode` envelope's `GeneratedContent`.
- Watchdog/clock reconciliation (decided here, not deferred to a doc comment): the JSC watchdog is driven by the envelope `timeout` — the work clock, reset by progress — and must never fire at `waitSeconds`. Elevation exists to keep the suspended JSC context alive past `waitSeconds`; today `MultiToolConfiguration.executionTimeLimit` and the elevation default are both 5 s, which would kill the context at the instant of elevation. `executionTimeLimit` becomes the default and ceiling for `timeout`, not a parallel killer. Update `MultiToolConfiguration` docs and the `JSCInterpreter(timeLimit:)` wiring accordingly.
- Outer elevation composition: Router's native mount wraps `MultiTool` in `ElevatingTool` like any tool. A snippet that runs past `waitSeconds` elevates while its inner promises stay in flight: the pending items are the promise plus a suspended JSC context; call settlements and elicitation answers keep resolving until the snippet ends in its terminal event. There is exactly one elevation point — no snippet ever branches on a pending envelope mid-code; inner calls never elevate.
- Two guards on suspended contexts: a `MultiToolConfiguration` cap on live suspended JSC contexts (exceeding it is a repairable in-band error), and the hard unblock — `cancel(completionToken)` and the session-end sweep reject each pending promise, drain the microtask queue, and remove the context within the time limit (extends the existing cancellation-mid-snippet guarantee; wire the interpreter's pending-promise rejection into the mailbox canceler for the outer run).

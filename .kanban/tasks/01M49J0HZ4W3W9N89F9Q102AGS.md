## Goal

The user decided (2026-10-06): drop Fortran from the semantic diff. See git.md decision 13.

## Why

With tree-sitter-fortran 0.6.0, the Rust crate `swissarmyhammer-sem` finds no Fortran function, subroutine, or module: the grammar keeps each name in a `*_statement` child, and the Rust name reader does not look there. The port copied that result, thus each Fortran golden expects no change. Fortran support gives no value.

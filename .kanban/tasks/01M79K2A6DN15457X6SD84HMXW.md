## What
Request from testudoapp-75, after card ^6a4w6a3. With an embedder, the hint searcher and the discovery searcher of one bundle each embedded the catalog at their first search, and each session embedded it again.

- `SearchIndexCache.sharedEmbedding(for:embedder:)` (Sources/FoundationModelsMultitool/Discovery/SearchIndexCache.swift) gives one `SharedCatalogEmbedding` (FoundationModelsMetadataRegistry) for each catalog and embedder identity. It keeps the 8 used last.
- The embedder identity: the `ObjectIdentifier` of a class instance, or the new public `IdentifiedEmbedding.embeddingIdentity`. An embedder with no identity shares its embed only inside one bundle. The slot keeps the embedder, so the identity cannot go to a new object.
- `FailureObservingEmbedding` records a failed embed. The cache drops that slot, so the next bundle embeds again.
- `RegistryBundle.init` builds both searchers with `MetadataSearcher(sharing:...)` when it has an embedder.

## What

Router now owns pooled residency by ARC. `LanguageModelProfile.release()` is deleted (router `^m8vj0jr`, in `main` at `efe0147`), a resident model is freed when the last reference to it goes away, and `Router.resolve` drains the pending evictions before it measures the host budget. Card `^wbya1jz` took the two `profile.release()` call sites out of this repo's Swift code.

`plan.md` still teaches the deleted call. Two places, in the Router surface summary:

- `plan.md:340-341` — "One profile is resident at a time (RAM budget); release before resolving another."
- `plan.md:347` — "``LanguageModelProfile`` — the resolved handle set: `.standard` and `.flash` are `RoutedLLM`, `.embedding` is a `RoutedEmbedder`; `release()` evicts them."

Both sentences name an API that no longer exists, so a reader who follows them writes code that does not compile.

What the text should say instead, confirmed against the router source at `efe0147`:

- `ResidencyHold` is the ARC owner. Each of the three handles holds it strongly, so a tool that keeps only `profile.flash` keeps that model resident, and a live session keeps the profile reachable.
- Dropping the last reference frees the models. There is nothing to call.
- The next `Router.resolve` drains the pending evictions under its pool lock before it measures the host budget, so the next resolve prices against the freed bytes.

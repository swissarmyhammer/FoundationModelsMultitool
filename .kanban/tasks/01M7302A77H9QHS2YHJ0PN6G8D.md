## What
D128 (e): the App Sandbox is the sandbox in Testudo, and the shell of OpenTestudo has the full rights of the user. Thus Multitool has no Seatbelt. This is a deletion (ARCHITECTURE.md: no backward compatibility, no shims).

- Delete `Sources/FoundationModelsMultitool/Capabilities/Shell/SeatbeltSandbox.swift`, `CommandSandbox.swift` (with `SandboxedInvocation` and `UnconfinedSandbox`) and `SandboxPreflight.swift`.
- Delete `Tests/FoundationModelsMultitoolTests/SeatbeltSandboxTests.swift`, `CommandSandboxTests.swift`, `SandboxPreflightTests.swift` and `SandboxSurfaceTests.swift`.
- Remove the `sandbox:` parameter from the two `withShell` overloads in `Surface/MultiToolBuilder+Capabilities.swift`, from `ShellCapability.init` (`Capabilities/Shell/ShellCapability.swift`) and from `ShellRunner` (`ShellRunner.swift`, also `resolvedSandboxDirectories`). `ShellRunner` starts `/bin/sh -c <command>` directly.
- In `Capabilities/Shell/Execute.swift`: remove the preflight (`runner.sandbox`, the `catch let error as SeatbeltSandboxError`) and `correction(for: SeatbeltSandboxError)`, and the comments about the seatbelt gate.
- Remove the sandbox cases from `ShellRunnerTests.swift`, `ShellCapabilityTests.swift`, `RegisteredJournalOpTests.swift` (`JournalOpProbeSandbox`, the `sandbox:` argument of `makeShellRegistry`) and `Tests/FoundationModelsMultitoolTests/Fixtures/ShellExecuteFixtures.swift`. If a test used a probe sandbox only to see the run context (the journal op), change it to read that context from a real run, not delete the check.
- IntegrationTests: `IntegrationTests/Tests/FoundationModelsMultitoolIntegrationTests/Support/ShellRunContextProbe.swift` is a `CommandSandbox`. Remove it, and change each scenario that uses it to read the run context in a different way (for example from the command output), so the scenarios still check the same thing.
- Doc comments in `Surface/MultiToolBuilder.swift` (line 13) name `withShell(storeDirectory:sandbox:...)`; change them.

`PathGuard` and `PathContainment` stay (D21). Only their comments change, in the docs task.
